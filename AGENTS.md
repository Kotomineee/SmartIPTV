# Preferências do projeto

- Preserve o README.md exatamente como o proprietário o deixou; não o edite nas atualizações.
- Publique releases pela conta autenticada Kotomineee. O GitHub Actions deve apenas testar e gerar os arquivos, sem publicar como bot.
- Releases devem conter somente o título da versão e os arquivos, com a descrição vazia e sem notas de atualização.
