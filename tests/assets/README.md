`resume.mp4` é um vídeo sintético de 20 segundos criado para os testes deste projeto, com imagem de cor sólida, dois tons de áudio AAC (português/inglês) e uma legenda em português. Não contém conteúdo de provedores IPTV.

Os testes verificam decodificação, seleção de faixas, retomada, conclusão e avanço automático com este arquivo servido pelo provedor HTTP local de `tests/provider.py`.
